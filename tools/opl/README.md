# Effect renderer

`opl3.c`, `opl3.h` and `LICENSE` are unmodified Nuked-OPL3, commit
`765ec962e473aeb767e4cba74ffdc8f588ffbfe8`, from
https://github.com/nukeykt/Nuked-OPL3 (LGPL-2.1-or-later).
`oplfx.c` is the headless register-script driver. The full audio build compiles
these sources locally and uses OPL2 mode, channel 0, at 49,716 Hz.
No third-party executable is distributed.
