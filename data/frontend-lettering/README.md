# Menu lettering

These are the approved shareware menu headings and pistol cursors. All editions
load these static records. Builds pack them into the native menu format; they do
not cut, compose, or fit the lettering again.

`headings.json` holds the original whole words and the composed headings.
`preview-titles.json` holds the approved floor and difficulty headings. The
difficulty bands leave palettes 0–2 for the New Game loading picture.
`cursors.json` holds both animation frames at both menu sizes, with transparent
background pixels. The record order in the native common page is fixed.

The source graphics are the bundled shareware files in `game-data/shareware`.
`source.json` records their hashes and the static record hashes. Licensed
registered and Spear graphics are not inputs to this lettering.
