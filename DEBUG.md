# Cheat and debug keys

These only work while you play: not in menus or demos, while you die, or at
the end of a floor.

## Cheats

- **M + L + I** (held together): 100% health, 99 ammo, both keys and the chain
  gun. Your score goes back to 0.
- **B + A + T**: shows the original Commander Keen message. Nothing else.
- **Shift + Option + Delete**: shows "Debugging keys are now available!". The
  Tab keys work without it.

## Debug keys

Hold Tab and press the key.

| Key | What it does |
| --- | --- |
| G | God mode on/off. |
| I | Free items: 100,000 points (with the extra lives), 99 health, the next weapon up to the chain gun, and 50 ammo (99 max). |
| H | Hurts you for 16 points. |
| E | Ends the floor. |
| W | Warps to a floor. Type 1-10 (1-21 in Spear). In Wolfenstein it's a floor of the current episode. |
| S | Slow motion on/off. |
| V | Adds 0-8 extra VBLs to each frame. |
| B | Sets the border color, 0-15. |
| C | Counts statics, doors, actors and active actors. |
| F | Shows your X, Y and angle. |
| M | Shows memory use. |
| T | Page viewer: W walls, S sprites, D effects, I effect info, Left/Right to step, Esc to leave. |
| P | Pauses on the plain screen. Any key goes on; Return or Enter, then any key, quits. |
| Q | Quits the game. |
| X | Shows "Extra stuff!". |
| N | No clipping on/off. Spear only. |

The number prompts take Return or Enter. Esc cancels and Delete erases.

In Spear, god mode also swaps in the god faces, and Tab + G + F10 toggles it
with a sound.
