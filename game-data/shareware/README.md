# Wolfenstein 3D shareware

Copy these extracted DOS data files here, keeping their original names:

```text
AUDIOHED.WL1
AUDIOT.WL1
GAMEMAPS.WL1
MAPHEAD.WL1
VGADICT.WL1
VGAGRAPH.WL1
VGAHEAD.WL1
VSWAP.WL1
```

From the project root: `python3 build.py --game shareware`.
Use `py -3` on Windows. Add `--inspect-only` for source validation.
See the [input guide](../README.md) for current image-build availability.
